This project compares three string-matching algorithms: **Naive Search**, **KMP**, and **Rabin–Karp**.

### What it does

- Accepts text and a pattern to search for.
- Finds every starting position where the pattern occurs.
- Shows comparisons and execution time for each algorithm.
- Includes performance analysis on randomly generated text.

### Example input

- Text: `AABAACAADAABAABA`
- Pattern: `AABA`

The pattern occurs at positions `0`, `9`, and `12`.
